# Jost

Jost is copyright 2020 The Jost Project Authors (https://github.com/indestructible-type), distributed under the bundled SIL Open Font License 1.1.

- `Jost-wght.ttf`: official variable font retrieved 15 November 2026 from https://github.com/google/fonts/tree/main/ofl/jost. Embedded by the R HTML build so the interactive poster needs no external font request.
- `Jost-Regular.ttf`, `Jost-Black.ttf`, `Jost-Italic.ttf`, `Jost-BlackItalic.ttf`: existing Jost static fonts copied from the author's installed font collection, bundled under the same OFL. The R poster explicitly registers these files as `Jost Poster`, making font selection independent of the system defaults. Black is used for bold headings; all poster type is Jost.
- `Jost-OFL.txt`: full original font licence retrieved from the Google Fonts Jost directory.

No university logo or branding assets are included.
