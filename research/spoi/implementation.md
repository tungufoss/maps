# Interactive spói poster

Goal: build a real reproducible R/Leaflet poster from the journal-linked Dryad data, with SQLite as the committed data artifact.

Architecture: Python's standard library imports both source tables into SQLite, checks publisher MD5s, preserves source rows, and records explicit quality flags. R reads SQLite, creates a Leaflet HTML widget over default OpenTopoMap tiles and a separate designed static poster over cached Natural Earth geography/relief. Small browser-side controls select birds, annual cycles, calendar windows and elapsed observations; no R or database server is needed to view the prepared HTML. The tiled background needs internet.

Files: `scripts/build_spoi_db.py`, `tests/test_spoi_db.py`, `data/spoi/spoi.sqlite`, `data/spoi/source.json`, `research/spoi/build.R`, `research/spoi/poster.css`, `research/spoi/poster.js`, `research/spoi/README.md`, `previews/spoi/index.html`, `previews/spoi/poster.png`, `.gitignore`, `.quartoignore`.
